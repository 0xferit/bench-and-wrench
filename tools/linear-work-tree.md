# Linear Work Tree

**Relationship: Curated.** This entry highlights the hosted app. Authorship and maintenance are not claimed by this collection.

Linear Work Tree arranges Linear initiatives, projects, milestones, and open assigned issues into a collapsible tree. It keeps an issue's larger purpose visible alongside its status, priority, estimate, and due-date information.

## Why it earns a place

A flat issue list is useful for choosing the next task, but it can hide how that task fits into a project or initiative. Linear Work Tree makes those relationships visible in one view.

You can fold the tree to its projects for an overview, unfold branches for detail, and search by title or identifier. Search highlights matching work and its surrounding context rather than removing the rest of the tree. The summary brings open, overdue, and in-progress issue counts and estimated points together.

## When it is useful

- Getting oriented across work that spans several projects.
- Seeing which milestone and initiative an assigned issue supports.
- Reviewing overdue work within its project and milestone.

## Limits to understand

Your own work requires a Linear connection. Without one, the app displays explicitly labeled, made-up example data. Those examples are not a view of your workspace.

The app describes its issue scope as open assigned issues, so it should not be treated as a complete workspace inventory. Its summary reports work and estimated points, not a completion forecast.

Folding, unfolding, and search highlighting were checked with the example data. The authenticated Linear connection has not been verified for this entry. A source repository and license have not been identified here.
